One line, under 200 characters, in which a home Wi-Fi router excuses itself
for dying at the climax of a movie. Built for the make.fun competition
[u-carbon-forge-the-router-confesses-f98f6b9e](https://make.fun/bounty/u-carbon-forge-the-router-confesses-f98f6b9e).

`main.py` (stdlib only) copies `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt`,
validating that it is a single non-empty line of at most 200 characters.
